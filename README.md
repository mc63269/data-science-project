# Data Science Projects

This repository brings together my data science coursework and projects. It demonstrates my developing skills in data preparation, exploratory analysis, visualization, and communicating findings.

## Project Collection

| Project | Focus | Status |
|---|---|---|
| [Airline Passenger Analysis](airline-passengers/) | Exploring long-term trends and seasonal patterns in historical monthly passenger data | Completed |

## Repository Organization

Each project is organized in a separate folder containing its analysis notebook or Python scripts, visualizations, dependency information, and project documentation.

Each project's README explains:
- The research question
- Dataset sources and usage permissions
- Methods and tools
- Key findings and limitations
- Instructions for reproducing the analysis

## Tools and Skills

Tools used across the projects include Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, and Seaborn. Specific dependencies are documented within each project.

## Data and Responsible Sharing

Data sources and usage conditions are documented separately for each project. Passwords, API keys, personal data, and restricted datasets must not be uploaded.

## Acknowledgements

Projects may build on coursework and learning resources. Relevant sources, contributions, and assistance are acknowledged in the individual project documentation.
